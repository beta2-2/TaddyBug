# Taddy Bug

画面をタップしてキャラクターを浮かせ、上下のブロックの隙間をくぐっていく小さな2Dゲームです。ブロックを一組通り抜けると1点。ブロックや地面に当たるとゲームオーバーです。

## 遊び方

Unity 6000.0.43f1 でプロジェクトを開き、`Assets/Scenes/SampleScene.unity` を再生します。エディターではゲーム画面を左クリックするとスタートし、その後はクリックするたびにキャラクターが上昇します。ゲームオーバーのあと、もう一度クリックすると最初から遊べます。

## 障害物とキャラクターの設定

ブロックは画面の左端を過ぎると右側に戻り、そのたびに隙間の高さが変わります。シーン内のブロックを選ぶと、Inspector の `Block` で高さの下限と上限、`Scroll Object` で移動速度を変更できます。

キャラクターが一度のタップでどれくらいの勢いで上がるかは、`TaddyBug` プレハブの `Flap Velocity` で調整できます。
